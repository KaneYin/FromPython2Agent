# Browser Blog Lab Exports

Complete [Week 4](../../weeks/04_blog_authorization.md) in the FastAPI Interactive browser lab. This directory is for your own exported implementation and test evidence.

Record the route/method used to modify a post, the database/session type, the non-author rejection status, and the before/after database values. Exporting the browser code is optional; the cross-user authorization check is part of the roadmap.

No third-party browser-course source code is bundled here.
