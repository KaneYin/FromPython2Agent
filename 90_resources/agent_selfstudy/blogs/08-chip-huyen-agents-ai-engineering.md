## 中文摘要

Chip Huyen 从 Russell & Norvig 的经典定义出发——agent 是"感知环境并作用于环境的东西"，其能力由**环境**与**可用动作集合**刻画——为 LLM Agent 建立了一个比"LLM+工具"更扎实的分析框架。全文围绕决定 Agent 能力的两大支柱展开：**工具**与**规划**。工具被分为三类：知识增强（context 构建，如检索、SQL、网页浏览）、能力扩展（弥补模型短板，如计算器、代码解释器）、写操作（真正改变外部世界，如发邮件、改数据库，风险也最高）；并讨论了工具选择的两难——工具越多能力越强，但模型理解与用好它们的难度也越大。规划部分覆盖串行/并行/条件式等模式及 ReAct、Reflexion。最出彩的是对**失败模式**的坦诚分析：多步任务的复合错误（每步 95% 准确率，10 步后只剩 60%）、工具带来的高风险、以及 Agent 评测的新难题。作者特别说明此文与 Anthropic《Building Effective Agents》概念上对齐，但侧重"为什么这样work、如何work"，而非罗列模式。

## 为什么值得读

这是目前把"Agent 为什么难做好"讲得最透的中文社区外文长文之一：复合错误率的量化直觉、工具分类框架、失败模式清单，都是动手前必须建立的风险意识；与 Anthropic 官方指南对照阅读，能同时获得"模式词典"和"原理解释"两套视角；配图（SWE-agent、ReAct、Reflexion 示意图）质量很高，适合做学习笔记的骨架。
